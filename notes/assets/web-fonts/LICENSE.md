# Proof sheet web fonts

Latin subsets downloaded from Google Fonts (fonts.gstatic.com) on 2026-10-03 and embedded
into each proof sheet so it renders offline. All are licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org).

| File | Family | Designer |
|---|---|---|
| caveat-latin.woff2 | Caveat (variable 400 to 700) | Impallari Type |
| pinyon-script-latin.woff2 | Pinyon Script | Nicole Fally |
| jost-latin.woff2 | Jost (variable 300 to 600) | Owen Earl (indestructible type*) |
| cormorant-garamond-500-latin.woff2, cormorant-garamond-500i-latin.woff2 | Cormorant Garamond 500 | Christian Thalmann |

Chinese fonts (LXGW WenKai TC, Ma Shan Zheng, Noto Sans SC, all OFL) are fetched per proof
as tiny subsets and cached in out/.fontcache (not committed).
