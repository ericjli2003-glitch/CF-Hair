# Plotter fonts

Single-stroke SVG fonts used by `src/providers/hershey.ts`, copied from the
`hersheytext` package (https://github.com/techninja/hersheytextjs, v2.0.0), which in turn
takes them from Evil Mad Scientist's Hershey Text Inkscape extension.

| File | Font | Licence |
|---|---|---|
| EMSFelix.svg | EMS Felix (derivative of Felipa by Fontstage) | SIL Open Font License 1.1 |
| EMSReadability.svg, EMSReadabilityItalic.svg | EMS Readability (derivative of Source Sans Pro Light by Adobe) | SIL Open Font License 1.1 |
| EMSAllure.svg | EMS Allure (derivative of Allura by TypeSETit) | SIL Open Font License 1.1 |
| HersheyScript1.svg | Hershey Script 1-stroke | Hershey fonts licence (free use with attribution) |

Single-line conversions by Sheldon B. Michaels and Windell H. Oskay (Evil Mad Scientist).
